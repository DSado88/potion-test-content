# Potion Test Content

This repository contains diverse test documents for QA testing the Potion document browser.

## Structure

- `basics/` — Fundamental markdown formatting
- `edge-cases/` — Unusual content that may break renderers
- `nested/` — Deeply nested folder structures
- `rich-content/` — Tables, code blocks, math, diagrams
- `real-world/` — Realistic document examples

## Quick Reference

| Category | Files | Purpose |
|----------|-------|---------|
| Basics | 6 | Headers, lists, links, images, emphasis |
| Edge Cases | 8 | Empty files, huge files, special chars |
| Nested | 5+ | Deep folder hierarchy testing |
| Rich Content | 5 | Tables, code, math, frontmatter |
| Real World | 4 | Meeting notes, API docs, changelogs |
